# Market data adapter\n\n`api/market.js` is the server-side boundary for live market data. Provider credentials are never placed in the iPad/browser bundle.\n\nConfigure these Vercel environment variables when a provider is selected:\n- `MARKET_DATA_API_URL` — provider endpoint accepting a `symbol` query parameter\n- `MARKET_DATA_API_KEY` — provider credential, stored server-side only\n\nIf either the provider is unavailable or the request fails, the endpoint returns a demo-mode response. The UI must continue operating rather than displaying NaN/blank data.\n\nThe provider contract is intentionally generic so the dashboard can later support a chosen market-data vendor without coupling the interface to one vendor.\n
